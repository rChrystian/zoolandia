# Zoolândia Kids

App React Native (Expo) de um zoológico infantil, organizado conforme o padrão do material enviado: `src/pages`, uma pasta por tela, `index.js` e `styles.js` separados e navegação Stack com React Navigation.

## Executar

1. Instale o Node.js e o Expo CLI, se ainda não estiverem instalados.
2. No diretório deste projeto, execute `npm install`.
3. Execute `npm start` e abra no Expo Go, em um emulador ou no navegador.

O `App.js` centraliza as rotas Stack. As 11 telas previstas são Splash, Cadastro, Login, BemVindo, Home e os seis territórios.
